# Portfolio Build Plan

## Stack
- Next.js 14 (App Router)
- Tailwind CSS v3
- Framer Motion (animations)
- react-type-animation (typing effect)
- react-particles (background particles)
- lucide-react (icons)

## Sections
1. Hero - typing animation, CTA buttons
2. About - emotional, premium content
3. Skills - cards with animated progress
4. Projects - glassmorphism cards
5. Timeline - journey milestones
6. Contact - email form + social links
7. Footer - minimal

## Features
- Dark/Light mode toggle
- Smooth scroll animations
- Glassmorphism + glow effects
- Fully responsive
- SEO optimized
